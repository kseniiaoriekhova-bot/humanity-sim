# Шляхи людства / Wege der Menschheit

Дослідницька модель політичних систем людства з 1900 до 2100 року. Це **не передбачення**: модель показує механізми, тобто чому системи ламаються і що з'являється на їхньому місці, і те, як результат залежить від припущень.

- **Шість блоків:** США, Європа (ЄС), Україна, Росія, Китай, Глобальний Південь.
- **Групи в кожному блоці:**
  - прості люди
  - освічені претенденти
  - еліти
  - держава й армія
- **Потреби й почуття груп.** Кожна група має потреби (достаток, безпека, статус, голос, належність, сенс) та емоції (гнів, страх, надія, довіра, гордість).
- **Теорії, на яких тримається модель:**
  - структурний тиск за Турчиним
  - легітимність за Вебером
  - інклюзивні інституції за Аджемоглу та Робінсоном
  - поширення ідей
- **Кризи:**
  - реформи
  - придушення
  - популізм
  - протестний перехід
  - революція
  - реакційна диктатура
  - переворот
  - захоплення влади платформами (технофеодалізм)
  - розпад
- **Перевірка на історії 1900–2025:** історичні шоки задано ззовні, переходи модель рахує сама.
- **Можливі майбутні 2025–2100:** сотні прогонів. Повзунки задають автоматизацію, концентрацію платформ, регулювання, клімат і геополітичну напругу.
- Мови: українська та німецька.

## Запуск

Відкрийте `index.html` у браузері. Або зберіть один файл:

```
python3 build.py      # -> dist/index.html
```

## Cloudflare

Це Worker лише зі статичними файлами (`wrangler.jsonc`, тека `dist/`). Готовий `dist/index.html` уже лежить у репозиторії, тож команда збирання не потрібна: достатньо `npx wrangler deploy`. Якщо `dist/` треба зібрати заново, команда збирання — `python3 build.py`.

## Файли

- `js/data.js`: блоки, режими, лади, ідеології, стартові стани 1900 і 2025, реальна історія, шоки, джерела
- `js/model.js`: сама модель (економіка, суспільство, політика, кризи, війни, багато прогонів)
- `js/people.js`: люди-представники та їхні щоденники
- `js/i18n.js`: тексти UK/DE
- `js/ui.js`: інтерфейс
